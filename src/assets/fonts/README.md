# Window title font

Noto Sans bold restores the desktop's original window title typeface. These
Latin and Latin Extended WOFF2 subsets are served locally, so rendering does
not depend on Google's font servers. The desktop uses Tahoma as a fallback.

Source: [Google Fonts Noto Sans](https://fonts.google.com/noto/specimen/Noto+Sans),
downloaded 28 October 2026 using its weight-700 CSS endpoint. The font is
distributed under the [SIL Open Font License](OFL.txt), included here.
